AgriData AI V3.3 — ผลผลิตต่อไร่ พร้อมที่มา สศก.

วิธีติดตั้ง:
1) แตก ZIP
2) GitHub > agridata-ai > Add file > Upload files
3) อัปโหลด app.py, data.csv, province_data.csv, requirements.txt
4) Commit changes แล้วรอ Streamlit รีโหลด

ข้อมูลระดับอำเภอ: 287 รายการ
- 219 รายการมีผลผลิตต่อไร่จากไฟล์ Excel เดิม คงค่าเดิม
- 68 รายการไม่มีค่าผลผลิตต่อไร่ ได้คัดค่าเฉลี่ยระดับจังหวัดจาก สศก. แทน โดยไม่คำนวณค่าใหม่
- ใส่ปีอ้างอิง สศก., ตาราง/หน้า และลิงก์อ้างอิงให้ทุกแถว
- ค่าจังหวัดที่ใช้ประกอบอำเภอไม่ใช่ค่าที่สำรวจจริงในอำเภอ
- พื้นที่เก็บเกี่ยวรายอำเภอที่ไม่มีข้อมูล 58 รายการ ไม่สมมติตัวเลข
- 49 รายการของค่าที่เติมมีปี สศก. ต่างจากปีข้อมูลระดับอำเภอ (ตรวจหมายเหตุ)

ไฟล์ Excel แยกให้ตรวจทานโดยละเอียด ไม่จำเป็นต้องอัปโหลด XLSX ไป GitHub หากใช้ CSV ที่ให้มาแล้ว
ตัวเลข สศก. อ้างอิงจากตารางสรุประดับจังหวัดที่อยู่ในไฟล์ต้นฉบับของผู้ใช้ และควรตรวจสอบเทียบ PDF สศก. โดยตรงก่อนใช้ในรายงานทางการ
