AgriData AI V3.1 — หน้าแรกแชทใหญ่ + Dashboard ด้านล่าง

สิ่งที่เปลี่ยนจาก V3.0
- หน้าแรกมี Chatbot อยู่ด้านบนทันที (แสดงข้อความในกรอบสูง 500 px)
- ช่องพิมพ์อยู่ต่อจากประวัติแชท ไม่ลอยไปท้ายหน้าเว็บ
- Dashboard อยู่ด้านล่างแชทในหน้าเดียวกัน
- เพิ่มฟอนต์ภาษาไทย Prompt (หากเปิด Google Fonts ไม่ได้ จะใช้ฟอนต์สำรอง)
- ขยายขนาดตัวอักษร หัวข้อ ปุ่ม ตัวกรอง และกราฟ
- ปุ่มตัวอย่างคำถาม 4 แบบ กดเพื่อถามได้ทันที
- ยังคง CSV เดิมทั้ง 2 ระดับ จังหวัด/อำเภอ และโค้ดคำนวณเดิม
- ลดข้อความที่มาของข้อมูลในคำตอบแชทให้กระชับ (รายละเอียดอยู่ในตาราง)
- ยังมีเมนูตรวจสอบคุณภาพและข้อมูลต้นฉบับ

การติดตั้ง
1. แตก ZIP
2. เข้า GitHub repository agridata-ai ของคุณ (สาขา main)
3. กด Add file > Upload files
4. อัปโหลด 4 ไฟล์ app.py, requirements.txt, data.csv และ province_data.csv
5. Commit changes แล้วรอให้ Streamlit อัปเดต
6. รีเฟรชเว็บเดิม https://agridata-ai-ldd5.streamlit.app

คำแนะนำทดสอบ
- แชทต้องอยู่เหนือ Dashboard หน้าแรก และช่องพิมพ์กว้างอ่านง่าย
- ลองคำถาม "ผลผลิตอ้อยจังหวัดขอนแก่น" และ "ขอรายอำเภอด้วย"
- Dashboard ยังคงมีผลผลิตต่อไร่ (กก./ไร่) เป็นตัวชี้วัดหลัก
- หากเว็บ Deploy error ให้เปิด Manage app > Logs แล้วส่งข้อความ error มาแก้ไข

ความปลอดภัย: อย่าใส่ GEMINI_API_KEY ใน app.py หรือ GitHub; เก็บเฉพาะ Streamlit Secrets
หมายเหตุ: ผ่านการตรวจไวยากรณ์ Python และโครงสร้างไฟล์ ยังไม่ได้ทดสอบบน Streamlit Cloud จริง
