AgriData AI | สร้างฐานข้อมูลใหม่จากไฟล์ Excel ต้นฉบับทั้ง 8 จังหวัด
==============================================================

ที่มา:
ใช้ไฟล์ต้นทาง 8 จังหวัดที่ผู้ใช้ส่งไว้ในแชต ไม่ได้นำไฟล์ data.csv / province_data.csv / Excel ที่ดัดแปลงในเวอร์ชันก่อนมาใช้เป็นต้นฉบับ
อ่านชีต "ฐานหลัก_ปรับตามสศก" และ "สศก_ยอดจังหวัด2568" ในแต่ละไฟล์
ไม่ได้เขียนทับ Google Drive / Google Sheets หรือแก้ไขไฟล์เดิมใด ๆ

รายการข้อมูล:
- ระดับจังหวัด: 40 แถว (8 จังหวัด × 5 พืชต่อจังหวัด ตามที่ระบุในแต่ละไฟล์)
- ระดับอำเภอ: 590 แถว (118 อำเภอ × พืชที่อยู่ในฐานต้นทาง)
  มีข้อมูลตัวเลขผลผลิตรายอำเภอ 287 แถว แยกเป็น
  · จากเอกสารระดับอำเภอ 205 แถว
  · คำนวณรวมจากข้อมูลย่อยรายอำเภอ 72 แถว
  · ประมาณการจากพื้นที่เก็บเกี่ยวอำเภอ × ผลผลิตเฉลี่ยจังหวัด สศก. 9 แถว
  · รายงานท้องถิ่นใช้อัตราคงที่ 1 แถว
  ยังไม่มีข้อมูลผลผลิตรายอำเภออีก 303 แถว
- ค่าผลผลิตต่อไร่ระดับจังหวัดจาก สศก. อยู่ครบทุกแถวจังหวัดและเป็นคอลัมน์ "ผลผลิตเฉลี่ยจังหวัด สศก." ในทุกแถวอำเภอ
  แต่ค่าดังกล่าวไม่ใช่การสำรวจผลผลิตต่อไร่รายอำเภอ ห้ามนำไปจัดอันดับอำเภอในฐานะผลจริง

สำคัญ:
- ผลผลิตรวมจังหวัดอ้างอิงจาก สศก. ไม่ได้ถูกคัดลอกไปยังช่อง "ผลผลิตรายอำเภอ"
- ช่องตัวเลขที่ไม่มีข้อมูลจะเป็นค่าว่าง (ไม่ใช่ 0 และไม่ใช่ตัวเลขเดา)
- ปีของรายอำเภออาจต่างจากปีอ้างอิงจังหวัด
- ทุกระเบียนเก็บชื่อไฟล์/ชีต/หมายเลขแถวต้นทาง พร้อมแหล่งอ้างอิงและ URL ที่มีในไฟล์ต้นทาง
- ข้อมูลชุดนี้ยืนยันการถอดจาก Excel ที่ผู้ใช้ส่ง แต่ไม่ได้ตรวจเทียบทุกตัวเลขกับ PDF สศก. ฉบับจริงอีกครั้ง

วิธีอัปโหลด GitHub:
1) แตก ZIP และเปิด GitHub repository agridata-ai ของคุณ
2) กด Add file > Upload files
3) อัปโหลดไฟล์ 4 ไฟล์ต่อไปนี้ไปไว้โฟลเดอร์รากของ repository (เลือกไฟล์ทับชื่อเดิม)
   - app.py
   - requirements.txt
   - data.csv
   - province_data.csv
4) กด Commit changes รอ Streamlit อัปเดต แล้วรีเฟรชหน้าเว็บไซต์
5) ที่หน้าแรก ลองถาม:
   "มีข้อมูลจังหวัดอุดรไหม" / "อุดร อ้อย" / "อุดรข้าว" / "อ้อยรายอำเภออุดร"
6) หากเปิดแอปไม่ได้ ให้ดู Streamlit logs จากหน้า Manage app; ไม่ต้องลบไฟล์ต้นฉบับอื่น

ตัวอย่างที่ควรเจอจากไฟล์ต้นทาง:
- อุดรธานี/อ้อยโรงงาน/ปีสถิติ 2568/ผลผลิตจังหวัด 6,740,547 ตัน/ผลผลิตเฉลี่ย 9,920 กก./ไร่
- อุดรธานี/อ้อยโรงงาน/รายอำเภอ: 20 แถว แต่ไม่มีตัวเลขผลผลิตรายอำเภอที่ยืนยันตามไฟล์ต้นทาง
- คำว่า "อุดรข้าว" ต้องแยกข้าวนาปีกับข้าวนาปรังคนละรายการ

โครงสร้างเว็บไซต์:
- ด้านบน: Chatbot ค้นค่าจาก CSV โดยตรง (ไม่ต้องใช้ Gemini API) รองรับชื่อย่อจังหวัดและสนทนาต่อเนื่อง
- ด้านล่าง: Dashboard ผลผลิตต่อไร่ (ข้อมูลจังหวัด สศก. ปีเดียวและพืชเดียว)
- ล่างสุด: รายละเอียดอ้างอิงและตารางข้อมูลครบทุกแถว

เวอร์ชันนี้เน้นความถูกต้องก่อน: ตัวแยกคำถามใช้กฎค้นหาจากฐานข้อมูลโดยตรง ไม่ได้เปิดใช้โมเดล AI ภาษาใด ๆ
เมื่อทดสอบฐานข้อมูลถูกต้องแล้ว ค่อยนำ Gemini หรือ open-source LLM มาใช้ช่วยทำความเข้าใจภาษาธรรมชาติ
โดยไม่อนุญาตให้โมเดลสร้างตัวเลขผลผลิตที่ไม่มีอยู่ในฐานข้อมูล
