AgriData AI V3.0 — Dashboard เน้นผลผลิตต่อไร่

วิธีติดตั้งโดยไม่ต้องแก้โค้ด
1) แตกไฟล์ ZIP นี้
2) เข้า GitHub repository agridata-ai (branch main)
3) Add file → Upload files
4) เลือก app.py, requirements.txt, data.csv, province_data.csv ที่อยู่ในโฟลเดอร์นี้ (ให้อยู่ระดับเดียวกัน ไม่ใช่โฟลเดอร์ย่อย)
5) Commit changes แล้วรอ Streamlit redeploy และรีเฟรชเว็บไซต์

ฟีเจอร์สำคัญ
- หน้าแรกเป็น Dashboard ผลผลิตต่อไร่ (กก./ไร่) — ตัวเลขใหญ่และเด่นที่สุด
- เลือกพืช ปี และระดับจังหวัด/อำเภอ ก่อนเปรียบเทียบ (ป้องกันเปรียบเทียบต่างปี)
- แสดงที่มาสั้น ๆ แยกแต่ละแถว: สศก., สำนักงานเกษตรจังหวัด, สำนักงานสถิติจังหวัด, คำนวณรวม หรือประมาณการ
- แสดงกราฟอันดับผลผลิตต่อไร่ ตามด้วยกราฟผลผลิตรวมและพื้นที่เก็บเกี่ยว
- ดาวน์โหลดตารางพร้อมแหล่งอ้างอิงเป็น Excel หรือ CSV
- Chatbot สนทนาต่อเนื่องจาก V2.2 ยังอยู่ พร้อมเมนูตรวจสอบข้อมูล
- ใช้ข้อมูล 287 รายการระดับอำเภอ และ 40 รายการระดับจังหวัด จาก CSV ที่ให้มา

ข้อควรระวัง
- ตัวเลขระดับอำเภอบางรายการไม่มีพื้นที่เก็บเกี่ยว: ไม่สามารถคำนวณผลผลิตต่อไร่ได้ และจะแสดงว่าง ไม่ใช่ศูนย์
- ค่าเฉลี่ยหลายจังหวัดเป็นค่าเฉลี่ยถ่วงน้ำหนักที่โปรแกรมคำนวณ ไม่ใช่ยอดที่ สศก. รายงานเป็นกลุ่มจังหวัด
- บางรายการเป็นค่าประมาณการ อย่าอ้างว่าเป็นผลผลิตจริงที่สำรวจรายอำเภอ
- หาก Repository เป็น Public ข้อมูล CSV สามารถถูกคนทั่วไปเห็นได้
- ยังไม่เชื่อม Google Sheets แบบเรียลไทม์; การแก้ไขฐานข้อมูลต้องอัปโหลด CSV ใหม่
- ยังไม่สามารถยืนยันได้ว่า Deploy สำเร็จบน Streamlit ของคุณจนกว่าจะอัปโหลดจริง
