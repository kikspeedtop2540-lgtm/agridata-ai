AgriData AI V3.4 — ตัดตัวเลือกปี / อ้างอิงละเอียด / Dashboard อ่านง่าย
===============================================================

ทำต่อจากเวอร์ชัน "สร้างข้อมูลใหม่จากต้นฉบับ 8 จังหวัด" เท่านั้น
ใช้ฐานข้อมูลจากไฟล์เดิมของเวอร์ชันล่าสุด ไม่กลับไปใช้ data.csv จากเวอร์ชันที่เติมตัวเลขอัตโนมัติ

ขั้นตอนติดตั้งเว็บไซต์เดิม
1. แตก ZIP ในคอมพิวเตอร์
2. GitHub > Repository agridata-ai > Add file > Upload files
3. เลือกไฟล์ 4 ไฟล์จาก ZIP: app.py, requirements.txt, data.csv, province_data.csv
4. Commit changes และเปิดเว็บไซต์ Streamlit เดิม แล้วกด Refresh
5. กด "ล้างบทสนทนา" และลอง "อุดร อ้อย", "อุดรข้าว", "ข้าว", "ขอรายอำเภอด้วย"
ไม่ต้องเปลี่ยน Gemini API Key เพราะตัวค้นหาตัวเลขใช้ข้อมูล CSV จริงแบบ deterministic

เปลี่ยนอะไร
- ไม่มีตัวกรองปีใน Dashboard; แสดงปีสถิติเป็นข้อความและเป็นคอลัมน์ในตารางเสมอ
- แสดง Chatbot ใหญ่ก่อน Dashboard ส่วน Dashboard มี 2 ตัวกรอง: พืช / จังหวัด
- เพิ่มขนาดฟอนต์ เพิ่มช่องว่าง กราฟแท่งผลผลิตต่อไร่แสดงค่าตัวเลขกำกับ
- แสดงแหล่งอ้างอิงแบบสั้นในตาราง และลิงก์ต้นฉบับ (ถ้ามี)
- แยกชื่อหน่วยงานหรือวิธีได้มาแต่ละแถว: สศก. / สำนักงานเกษตร-กรมส่งเสริม / ประมาณการ / หน่วยงานอื่น
- ไม่รวมผลผลิตหลายปี ไม่จัดอันดับผลผลิตต่อไร่อำเภอจากอัตราเฉลี่ยจังหวัด

แนวทางบอกแหล่งอ้างอิงที่ต้องรักษา:
A) ระดับจังหวัด: สำนักงานเศรษฐกิจการเกษตร (สศก.)
   สถิติการเกษตรของประเทศไทย ปี 2568 — เลขตาราง, หน้า, ปีสถิติ, URL สศก.
   นำ "ผลผลิตต่อไร่ (กก./ไร่)" ตรงจากคอลัมน์ต้นฉบับ ไม่คำนวณแทน
B) ระดับอำเภอ: ใช้ตัวเลขจากเอกสารอำเภอ/จังหวัดที่ตรวจพบในไฟล์ต้นทาง
   เช่น สำนักงานเกษตรจังหวัด/อำเภอ, กรมส่งเสริมการเกษตร, สศก., กรมพัฒนาที่ดิน หรือหน่วยงานอื่น
   แสดงชื่อหน่วยงานตามที่ระบุในแต่ละแถวจริง ไม่ใช้ชื่อเดียวกันครอบทั้งหมด
C) ระดับอำเภอ (ประมาณการ): 9 แถว คำนวณผลผลิตจากพื้นที่อำเภอ × ผลผลิตต่อไร่เฉลี่ยจังหวัด สศก.
   ป้าย "ประมาณการ" โดยชัดเจน; แยกแหล่งพื้นที่อำเภอจากแหล่งอัตราผลผลิต สศก.
D) "ผลผลิตเฉลี่ยจังหวัด สศก. (กก./ไร่)" ที่ปรากฏในแถวอำเภอทุกรายการ
   เป็นเพียงอัตราอ้างอิงระดับจังหวัด ไม่ใช่ค่าที่วัดจริงรายอำเภอ
E) 303 รายการที่ยังไม่มีผลผลิตรายอำเภอจะคงค่าว่าง ไม่ใช้ยอดจังหวัดแทน ไม่ใส่ 0

ภาพรวมข้อมูลที่ถอดจาก Excel ต้นฉบับ:
- จังหวัด 8 จังหวัด, ข้อมูลจังหวัด 40 แถว
- ข้อมูลอำเภอ 590 แถว (287 แถวที่มีตัวเลขผลผลิตรายอำเภอ, 303 แถวไม่มีตัวเลข)
- 287 แถวที่มีตัวเลข: จากเอกสาร 205, คำนวณรวมข้อมูลย่อย 72, ประมาณการพื้นที่ × ค่าเฉลี่ย สศก. 9, อัตราคงที่ในรายงานท้องถิ่น 1
- ตัวเลขคอลัมน์เดิมไม่ถูกแก้ไขในเวอร์ชันนี้ เพิ่มเฉพาะคอลัมน์ชนิดแหล่ง/ที่มาสั้น
- ข้อมูลอ้างอิงถอดตาม Excel 8 จังหวัด ไม่ได้ตรวจพิสูจน์ PDF ต้นฉบับทีละแถว
