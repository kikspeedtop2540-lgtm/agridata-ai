AgriData AI V3.4.2 — แก้กราฟผลผลิตต่อไร่ไม่แสดง

วิธีอัปเดต (แนะนำ):
1. เข้า GitHub repository agridata-ai สาขา main
2. กด Add file → Upload files
3. อัปโหลดเฉพาะ app.py จาก ZIP นี้ แทนที่ app.py เดิม
4. กด Commit changes, รอเว็บไซต์รีสตาร์ต แล้วรีเฟรชหน้า

ไม่จำเป็นต้องอัปโหลด data.csv, province_data.csv หรือ requirements.txt อีก หาก V3.4.1 ใช้งานอยู่แล้ว
(ไฟล์แนบครบชุดไว้เป็นสำรองเท่านั้น)

สาเหตุ: ชื่อคอลัมน์ผลผลิตต่อไร่ (กก./ไร่) มีจุด (.) ซึ่ง Vega-Lite อาจตีความ
เป็นเส้นทางฟิลด์ซ้อนในข้อมูล ส่งผลให้แท่งกราฟหายแม้ตารางมีตัวเลข
แก้ด้วยการสร้างคอลัมน์ plot ชื่อ ASCII ปลอดภัย: yield_kg_rai, province_name
และเพิ่ม fallback กราฟพื้นฐาน/ข้อมูลประกอบ

ไม่มีการเปลี่ยนตัวเลข CSV; ปีสถิติและแหล่งอ้างอิงยังอยู่เช่นเดิม
ถ้าเลือกมันสำปะหลังโรงงาน / ทุกจังหวัด ในฐานปัจจุบัน จะมีรายการสรุประดับจังหวัด 7 จังหวัด
จังหวัดที่ไม่มีแถวในชุด สศก. จะระบุด้วยหมายเหตุ ไม่สรุปว่าไม่มีการปลูก
