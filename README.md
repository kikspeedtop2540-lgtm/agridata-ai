# 🌾 AgriData AI — เว็บ Chatbot วิเคราะห์ข้อมูลผลผลิตการเกษตร (เริ่มฟรี)

ตัวอย่างทำงาน: Gemini API ตีความคำถามภาษาไทยเป็นเงื่อนไข → Python/Pandas ค้นและคำนวณจากไฟล์จริง → แสดงตาราง กราฟ และแหล่งอ้างอิง

**ค่าใช้จ่าย:** Streamlit Community Cloud มีแพ็กเกจฟรี และ Gemini API มี Free Tier (ขึ้นกับโมเดล บัญชี ภูมิภาค และโควตาขณะใช้งาน) ไม่ต้องเปิดระบบชำระเงินหาก Free Tier รองรับบัญชีคุณ

## 1) เตรียมข้อมูล

ไฟล์ `data.csv` ที่ให้มาเป็น **ตัวเลขสมมติทั้งหมด** เพื่อให้ทดสอบได้ทันที อย่าใช้รายงานราชการ!

นำข้อมูลจริงมาทับไฟล์ `data.csv` หรือใส่ไฟล์ `data.xlsx` ใน GitHub (ถ้ามี `data.xlsx` โปรแกรมจะอ่านไฟล์นั้นเป็นลำดับแรกโดยอ่านชีตแรก)

1 แถว = 1 จังหวัด + 1 อำเภอ + 1 พืช + 1 ปี (และชุดข้อมูลสถิติประเภทเดียวกัน)

คอลัมน์จำเป็น:
- `จังหวัด`, `อำเภอ`, `พืช`, `ปี`

คอลัมน์ตัวเลขที่รองรับ (อย่างน้อย 1 ตัว):
- `เนื้อที่เพาะปลูก (ไร่)`
- `เนื้อที่เก็บเกี่ยว (ไร่)`
- `ผลผลิต (ตัน)`
- `ผลผลิตต่อไร่` (ถ้ามี หน่วย กก./ไร่)

คอลัมน์อ้างอิงแนะนำ: `แหล่งข้อมูล`, `ลิงก์อ้างอิง`

> ถ้าไฟล์ต้นฉบับมีหลายชีต / หลายหัวตาราง / เป็นข้อมูลระดับจังหวัดปนระดับอำเภอ ให้จัดตารางก่อน ไม่เช่นนั้นอาจนับซ้ำหรืออ่านผิดหน่วย

## 2) สร้าง Gemini API Key ฟรี

1. เข้า https://aistudio.google.com/apikey
2. ลงชื่อเข้าใช้ Google → Create API key → เลือกหรือสร้างโปรเจกต์
3. เลือก Free Tier ถ้าบัญชีและภูมิภาคของคุณรองรับ (ไม่ต้องเปิด Billing เพื่อทดลอง)
4. เก็บ Key ไว้ส่วนตัว **ห้ามใส่ใน GitHub หรือแชตสาธารณะ**

โมเดลที่ใช้ในโปรแกรม: `gemini-3.5-flash-lite` (ตรวจสอบการรองรับบัญชีและโควตาที่ Google AI Studio)

## 3) สร้าง GitHub repository

1. สมัคร / เข้าสู่ https://github.com
2. กด New repository → ตั้งชื่อ `agridata-ai` → Public (ใช้เฉพาะข้อมูลที่เผยแพร่ได้เท่านั้น)
3. กด Add file → Upload files → อัปโหลด `app.py`, `requirements.txt`, `data.csv`, `.gitignore` (README.md ได้ด้วย)
4. Commit changes

ถ้าข้อมูลห้ามเผยแพร่ **อย่าใส่ใน public repo**. ทางเลือกคือ private repo + ตรวจสอบสิทธิ์ Streamlit ก่อนเปิดใช้.

## 4) เผยแพร่เว็บด้วย Streamlit ฟรี

1. เข้า https://share.streamlit.io แล้วเชื่อมบัญชี GitHub
2. Create app → เลือก GitHub repository `agridata-ai`, branch `main`, app file `app.py`
3. คลิก Advanced settings → Secrets และใส่:

```toml
GEMINI_API_KEY = "วาง_API_KEY_ของคุณ"
# ถ้าต้องการรหัสกลางก่อนเข้าเว็บไซต์ เปิดบรรทัดต่อไปนี้:
# APP_PASSWORD = "ตั้งรหัสที่ยากต่อการเดา"
```

4. Deploy → รอจนระบบขึ้น URL `https://<ชื่อที่ตั้ง>.streamlit.app`
5. แชร์ลิงก์ให้ผู้ทดลองใช้

**สำคัญ:** แม้ตั้ง `APP_PASSWORD` แต่ไฟล์ข้อมูลใน GitHub Public ยังคงมองเห็นได้จาก GitHub รหัสกลางไม่ใช่ระบบบัญชีผู้ใช้รายคน

## 5) เพิ่มข้อมูลใหม่

- GitHub → repo `agridata-ai` → เปิด `data.csv` → Edit (ดินสอ) เพื่อแก้ไขแถวเล็กน้อย แล้ว Commit
- หรือ Upload files → ใส่ `data.xlsx` จาก Excel จริง ลง repo → Commit
- Streamlit จะอัปเดตตามการเปลี่ยนแปลงของ repo โดยอัตโนมัติ (บางครั้งอาจต้องกดรีสตาร์ต)
- ถ้ามี `data.xlsx` อยู่ โปรแกรมจะเลือก `data.xlsx` แทน `data.csv`

## 6) คำถามที่ลองพิมพ์

- อันดับ 5 อำเภอที่มีผลผลิตข้าวสูงสุดในจังหวัดขอนแก่น ปี 2567
- เปรียบเทียบผลผลิตข้าวแต่ละจังหวัด ปี 2567
- แนวโน้มผลผลิตข้าวจังหวัดขอนแก่นย้อนหลัง 5 ปี
- อำเภอโคกโพธิ์ชัยมีเนื้อที่เก็บเกี่ยวข้าวเท่าไหร่ ปี 2567
- จังหวัดไหนมีพื้นที่เก็บเกี่ยวอ้อยมากที่สุด ปีล่าสุด

## ขอบเขต / ความปลอดภัย

- ระบบนี้ **ไม่ค้นข้อมูลจากอินเทอร์เน็ต** มาตอบ และไม่รู้ข้อมูลอื่นนอกจากที่บันทึกในไฟล์
- Gemini ใช้เพื่อแปลคำถามเท่านั้น; ตัวเลขคำนวณด้วย Pandas จากไฟล์ ไม่ใช่ AI คิดเลขเอง
- การจัดอันดับกับปีล่าสุดใช้ปีสูงสุดที่มีในชุดข้อมูลที่กรองแล้ว; อาจไม่เท่ากันกับปีล่าสุดในโลกจริง
- ไม่ควรมีแถวสรุปจังหวัดปนกับข้อมูลอำเภอ มิฉะนั้นจะนับซ้ำ
- ถ้ามีอำเภอ/พืช/ปีซ้ำกันหลายระเบียนโดยไม่มีเหตุผล อาจนับผลผลิตซ้ำ
- API Free Tier ของ Gemini สามารถมีโควตาและ Google อาจใช้ข้อมูลที่ส่งไปเพื่อปรับปรุงผลิตภัณฑ์: โปรแกรมพยายามส่งเพียงคำถาม + ชื่อพื้นที่/พืช + ประวัติคำตอบสั้น ๆ ไม่ส่งตัวเลขทั้งฐานข้อมูล แต่ **อย่าใช้คำถามที่มีข้อมูลลับ/ข้อมูลส่วนบุคคล**
- เว็บ Streamlit Community Cloud จะพักเมื่อไม่มีคนใช้นาน; ผู้ใช้อาจต้องกดปลุกแอป
- Shared password เหมาะทดลองเล็ก ๆ เท่านั้น; หากจะใช้ข้อมูลราชการที่ไม่เปิดเผย ให้พิจารณา private repo และระบบสิทธิ์ที่เหมาะสมก่อน

## ทดลองบนคอมพิวเตอร์ (ไม่จำเป็นสำหรับการเผยแพร่)

```bash
pip install -r requirements.txt
streamlit run app.py
```

สร้างไฟล์ `.streamlit/secrets.toml` บนคอมพิวเตอร์ตัวเองตามตัวอย่าง Secrets (ห้ามอัปโหลดขึ้น GitHub)
